# BeeMarket Stock Monitor

Дашборд товарного запаса BeeMarket: покрытие стока, dead stock, излишки и дефицит по матрице, брендам и филиалам, продажи, валовая маржа, GMROI и ABC-анализ.

**Сайт:** https://abdukhamidsaidov.github.io/beemarket-stock-monitor/
**Демо на вымышленных данных:** https://abdukhamidsaidov.github.io/beemarket-stock-monitor/?demo

## Как пользоваться

1. Откройте сайт и перейдите во вкладку **«Данные и настройки»**.
2. Перетащите две выгрузки из ERP:
   - **Отчёт об остатках на складах** (`products-stock-report-….xlsx`);
   - **Отчёт по продажам** (`report-export-….xlsx`, лучше с колонкой «Разница»).
3. Проверьте дату остатков и нажмите **«Обновить дашборд»**.

Каждая загрузка добавляет точку в график «Динамика: сток и покрытие».

## Где хранятся данные

- У сайта нет сервера: GitHub Pages отдаёт только статические файлы. Выгрузки читаются и считаются **в браузере** и никуда не отправляются. Политика безопасности страницы (CSP, `connect-src 'self'`) запрещает скриптам отправлять данные на сторонние адреса.
- Последний снимок хранится в IndexedDB этого браузера, история и параметры — в localStorage. На другом компьютере или в другом браузере данных не будет.
- Чтобы передать данные коллеге, нажмите **«Скачать снимок (.json)»** и отправьте файл по внутренним каналам. Коллега откроет его кнопкой **«Открыть снимок (.json)»**. Также открывается `snapshot.json` из артефакта Claude.
- **Удалить данные из браузера** — кнопка там же. Используйте её на чужих компьютерах.

> ⚠️ Не кладите реальные выгрузки и снимки в этот репозиторий: он публичный, и всё, что в нём лежит, доступно любому человеку в интернете.

## Структура проекта

```
├── index.html               главная страница (SEO, Open Graph, CSP)
├── 404.html                 страница «не найдено» для GitHub Pages
├── .nojekyll                отключает обработку Jekyll
├── site.webmanifest         установка на телефон как приложение
├── sitemap.xml              карта сайта для Google Search Console
└── assets/
    ├── css/styles.css       стили, тёмная тема, мобильная вёрстка
    ├── js/core.js           состояние, разбор выгрузок ERP, расчётная модель
    ├── js/ui.js             таблицы, графики, вкладки
    ├── js/app.js            загрузка файлов, хранение, снимки, демо, запуск
    ├── vendor/              Chart.js 4.4.1 и SheetJS 0.18.5 (локальные копии)
    └── img/                 favicon, иконки, картинка для соцсетей
```

Все пути относительные (`assets/...`). Поэтому сайт работает и по адресу `https://<user>.github.io/<repo>/`, и локально. Абсолютный путь `/beemarket-stock-monitor/` есть только в `404.html`: GitHub отдаёт эту страницу на любом уровне вложенности.

## Запуск локально

```bash
cd beemarket-stock-monitor
python3 -m http.server 8000   # или: npx serve .
# открыть http://localhost:8000/
```

Открывать `index.html` двойным кликом (`file://`) тоже можно, но IndexedDB в этом режиме работает не во всех браузерах.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `beemarket-stock-monitor`. Для Pages из приватного репозитория нужен платный план.
2. Загрузите в корень репозитория **содержимое** этой папки. `index.html` должен лежать в корне, а не во вложенной папке.
3. Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**. Выберите **Branch: `main`**, папку **`/ (root)`** и нажмите **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://<user>.github.io/beemarket-stock-monitor/`. Статус сборки виден во вкладке **Actions**.

## Обновление сайта

Измените файлы и загрузите их в `main` (через **Add file → Upload files** или `git push`). Pages пересоберётся автоматически. GitHub Pages кэширует файлы на 10 минут. Чтобы браузеры сразу получили новые CSS и JS, увеличьте `?v=1.0.0` в ссылках в `index.html`.

## Если меняется адрес сайта

При переименовании репозитория или аккаунта замените `abdukhamidsaidov.github.io/beemarket-stock-monitor` в файлах `index.html` (canonical, og:url, og:image, twitter:image, JSON-LD), `sitemap.xml` и `404.html`.
